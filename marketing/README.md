From the repository root, run `python3 marketing/compose.py` on macOS with Python 3, Pillow, Google Chrome, and the installed New York regular/italic system fonts; no app dependencies or new packages are needed. The tool uses only the captures in `marketing/raw/iphone/` and `marketing/raw/ipad/`, so the original dispatch directories and environment variables are not required. It writes six ordered PNGs to `marketing/out/iphone/` at 1290×2796 (`APP_IPHONE_67`) and six to `marketing/out/ipad/` at 2048×2732 (`APP_IPAD_PRO_3GEN_129`), plus per-frame measurements and SHA-256 hashes in `marketing/checks/`. Use `--device iphone`, `--device ipad`, or `--only 05` to rerender a selection; set `CHROME_BIN` if Chrome is installed elsewhere. Chrome renders the entire frame at the exact output size with device scale factor 1; it proportionally downscales the unchanged capture inside the bezel, and the device intentionally continues behind the bottom band. The compositor loads New York from the local system rather than redistributing fonts, rejects missing/wrong-device captures, missing fonts, text overflow, headline collisions and upscaling, and publishes the selected frames only after every render passes. Existing outputs remain untouched on a rendering failure; always check the command's exit status before uploading. See `REPORT.md` for the observed input-quality limitations and verification evidence.
